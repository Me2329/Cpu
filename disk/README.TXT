Welcome to PERRY-DOS 1.0
========================

This disk holds the PERRY-16 system software:

  COMMAND.PEX   the shell you are using (DIR, RUN, TYPE, MEM, EXPLORER ...)
  WORD.PEX      PERRY Word - text editor           (WORD README.TXT)
  EXCEL.PEX     PERRY Excel - spreadsheet          (EXCEL BUDGET.XLS)
  PAINT.PEX     PERRY Paint - mouse drawing, VGA   (PAINT)
  RAYCAST.PEX   3D maze demo, loads MAZE.WAD       (RAYCAST)
  HELLO.PEX     smallest possible program

Try the EXPLORER command: pick a file with the arrow keys and press
Enter - documents open in the program associated with their extension.

Everything here was written in PERRY-16 assembly, assembled with
tools/pasm.py and runs on the emulated 16-bit CPU.
